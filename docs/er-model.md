
# ER Model

![ER Diagram](er-diagram.png)

## Entities

### Artist

Исполнитель представляет собой музыкального артиста или группу, выпускающих альбомы и треки.
Каждый исполнитель имеет уникальный сценический псевдоним, под которым он известен слушателям.

**Identifier:**
`artist_nickname`

#### Attributes

| Attribute           | Description                                                                    |
| ------------------- | ------------------------------------------------------------------------------ |
| **artist_nickname** | Сценический псевдоним исполнителя. Уникальный в системе.                       |
| **artist_name**     | Настоящее имя исполнителя или название группы. Может совпадать у разных людей. |
| **birth_date**      | Дата рождения исполнителя или год основания группы.                            |
| **country**         | Страна происхождения исполнителя.                                              |
| **num_albums**      | Количество выпущенных альбомов (вычисляемый атрибут).                          |
| **num_songs**       | Количество треков исполнителя (вычисляемый атрибут).                           |

---

### Album

Альбом представляет собой коллекцию музыкальных треков, выпущенных исполнителем как единое произведение.

**Identifier:**
`(album_name, artist_nickname, release_date)`

Такой составной ключ выбран, поскольку один исполнитель может выпускать альбомы с одинаковым названием в разные годы (например, переиздания).

#### Attributes

| Attribute           | Description                      |
| ------------------- | -------------------------------- |
| **album_name**      | Название альбома                 |
| **artist_nickname** | Псевдоним исполнителя            |
| **release_date**    | Дата выпуска                     |
| **duration**        | Общая длительность альбома (сек) |
| **genre**           | Основной жанр                    |
| **num_songs**       | Количество треков                |

---

### Song

Трек представляет собой отдельную музыкальную композицию, которая может входить в альбом.

**Identifier:**
`(song_name, main_artist)`

Предполагается, что у одного исполнителя не может быть двух разных треков с одинаковым названием.

#### Attributes

| Attribute        | Description             |
| ---------------- | ----------------------- |
| **song_name**    | Название композиции     |
| **main_artist**  | Главный исполнитель     |
| **track_number** | Номер трека в альбоме   |
| **duration**     | Продолжительность (сек) |
| **release_date** | Дата выпуска            |
| **lyrics**       | Текст песни             |
| **genre**        | Основной жанр           |

---

### User

Пользователь — зарегистрированный слушатель музыкального сервиса.

**Identifier:**
`username`

Также уникальным является `email`.

#### Attributes

| Attribute             | Description                        |
| --------------------- | ---------------------------------- |
| **username**          | Уникальное имя пользователя        |
| **email**             | Уникальный адрес электронной почты |
| **password_hash**     | Хеш пароля                         |
| **registration_date** | Дата регистрации                   |
| **is_premium**        | Флаг премиум-подписки              |

---

### Playlist

Плейлист представляет собой пользовательскую подборку музыкальных треков.

**Identifier:**
`(playlist_name, user_name)`

Один пользователь не может иметь два плейлиста с одинаковым названием.

#### Attributes

| Attribute         | Description                               |
| ----------------- | ----------------------------------------- |
| **playlist_name** | Название плейлиста                        |
| **user_name**     | Автор плейлиста                           |
| **duration**      | Общая длительность                        |
| **num_songs**     | Количество треков                         |
| **is_default**    | Является ли плейлистом «Избранное»        |
| **is_public**     | Доступен ли плейлист другим пользователям |

---

### Listening History

История прослушиваний фиксирует каждый факт воспроизведения трека пользователем.

**Identifier:**
`(user_name, song_name, listened_at)`

Такой ключ выбран, потому что пользователь может слушать один и тот же трек многократно в разное время.

#### Attributes

| Attribute       | Description                |
| --------------- | -------------------------- |
| **song_name**   | Прослушанный трек          |
| **user_name**   | Пользователь               |
| **listened_at** | Дата и время прослушивания |

---

# Relationships

### Artist — Album

**Relationship:** *Artist releases Album*

**Type:** `1 : N`

* Один исполнитель может выпустить множество альбомов.
* Каждый альбом принадлежит одному исполнителю.

**Participation**

| Entity | Participation |
| ------ | ------------- |
| Artist | optional      |
| Album  | mandatory     |

---

### Album — Song

**Relationship:** *Album contains Song*

**Type:** `1 : N`

* Альбом содержит множество треков.
* Трек может входить в альбом или быть синглом.

**Participation**

| Entity | Participation |
| ------ | ------------- |
| Album  | mandatory     |
| Song   | optional      |

---

### User — Playlist

**Relationship:** *User creates Playlist*

**Type:** `1 : N`

* Один пользователь может создать множество плейлистов.
* Каждый плейлист принадлежит одному пользователю.

**Participation**

| Entity   | Participation |
| -------- | ------------- |
| User     | optional      |
| Playlist | mandatory     |

---

### Playlist — Song

**Relationship:** *Playlist contains Song*

**Type:** `M : N`

* Один плейлист может содержать множество треков.
* Один трек может входить в множество плейлистов.

**Participation**

| Entity   | Participation |
| -------- | ------------- |
| Playlist | optional      |
| Song     | optional      |

В реляционной модели связь реализуется через промежуточную таблицу.

---

### User — Song

**Relationship:** *User listens to Song*

**Type:** `M : N`
**Attributes on relationship:** `listened_at`

Связь реализована через сущность **Listening History**, которая хранит факт каждого прослушивания.

* Пользователь может слушать множество треков.
* Один трек может быть прослушан многими пользователями.

---

### Artist — Song

**Relationship:** *Artist performs Song*

**Type:** `M : N`

* Один трек может исполняться несколькими артистами (коллаборации, фиты).
* Один артист может исполнять множество треков.

**Participation**

| Entity | Participation |
| ------ | ------------- |
| Artist | optional      |
| Song   | mandatory     |

---
