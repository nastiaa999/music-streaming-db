# Генерация тестовых данных

Скрипт `generate_data.py` наполняет базу данных реалистичными тестовыми данными на основе реального датасета популярных треков Spotify.

## Источник данных

Используется датасет [Popular Spotify Datasets](https://www.kaggle.com/datasets/satyajeetkumarraj/popular-spotify-datasets) с Kaggle.

## Что генерирует скрипт

| Сущность | Количество | Описание |
|----------|------------|----------|
| Artists | ~2,500 | Уникальные исполнители из датасета |
| Albums | ~5,000 | 1-3 альбома на исполнителя |
| Songs | ~180,000 | Треки из датасета с автогенерацией текстов |
| Song-Artist links | ~200,000 | Связи M:N (основные + featured артисты) |
| Users | 3,000 | Случайные пользователи с разными возрастными группами |
| Playlists | ~12,000 | Системный плейлист «Избранное» + 2-4 пользовательских на каждого |
| Playlist-Song links | ~200,000 | По 5-25 треков в плейлисте |
| Listening History | 1,000,000+ | История прослушиваний за последний год |

## Использование

1. Скачайте датасет `Popular_Spotify_Songs.csv` и поместите его в корень проекта

2. Настройте подключение к БД в начале скрипта:
```python
conn = psycopg2.connect(
    "dbname=music_service user=admin password=1234 host=localhost port=5432"
)
```

3. Запустите генерацию:
```bash
python generate_data.py
```

## Особенности генерации

**Тексты песен** — генерируются автоматически на основе названия трека с использованием шаблонов (куплеты, припев, бридж).

**Профили пользователей** — создаются с разными музыкальными предпочтениями:
- Обычные пользователи слушают 2-3 жанра (250-400 прослушиваний)
- Меломаны (каждый 7-й) слушают все жанры (700+ прослушиваний)

**Коллаборации** — для 20% треков добавляются случайные featured-артисты сверх тех, что указаны в датасете.

**Временные метки** — все даты генерируются в реалистичных диапазонах (альбомы за последние 15 лет, прослушивания за последний год).

## Время выполнения

Полная генерация занимает 2-5 минут в зависимости от производительности системы и сети.
